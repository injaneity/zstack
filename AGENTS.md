# zane's coding setup

zstack is a fork of pstack, cut down to work in one thread. Skills live at `~/.pi/agent/skills/zstack/skills/<name>/SKILL.md`.

For any non-trivial coding task, read the **onigiri-mode** skill first and follow its routing table. It names the skill or playbook for the task and the principles that apply.

There are no subagents in this setup. Do not spawn, delegate, or fan out. Do the work yourself, in verifiable units, and review your own diff against the plan before calling it done.

Read a principle skill in full before applying it, and name the ones that changed a decision.
